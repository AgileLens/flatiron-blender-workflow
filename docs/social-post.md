# Social draft

Eight reference photos. An editable Flatiron Building in Blender.

We used GPT-6 Astra through Codex and Blender MCP to build the geometry, inspect views, then revise the facade and cornice. The result is a photo-guided architectural approximation with editable mesh geometry and materials. Dimensions and ornament include artistic guesses.

The successful construction pass used 63,929 uncached input tokens and 4,214 output tokens, plus 438,656 cached input tokens. Our public receipt also includes failed setup attempts and identifies the other models involved.

We are sharing the Blender file and replayable steps so others can try the workflow. Next: testing it on theater environments and in Apple Vision Pro.
